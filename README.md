### Priority Order

For most interviews, focus in this order:

1. **Core JS:** scope, closures, hoisting, `this`, prototypes
2. **Async JS:** promises, async/await, event loop
3. **Arrays/Objects:** methods, copying, destructuring
4. **DOM:** events, delegation, browser APIs
5. **Coding problems:** strings, arrays, recursion, hash maps
6. **Advanced topics:** generators, proxy, workers, performance
